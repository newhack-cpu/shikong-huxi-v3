#### P0-4：BHI 公式改为 v2 并补充溯源说明

报告中 4.2 节末尾的"原创特征——呼吸健康指数（BHI）"段落写的是 v1 公式
`BHI = 0.65×PM2.5/5 + 0.20×温度不适度 + 0.15×风险趋势`，必须改成 v2：

```
BHI = 0.55 × IPM + 0.15 × IT + 0.30 × IE

  IPM (污染强度分量) - 基于 GB 3095-2012 IAQI 分段非线性映射
  IT  (气象不适分量) - 基于 ASHRAE 55-2020 热舒适标准 + 风寒指数修正  
  IE  (暴露累积分量) - 基于 WHO 2021 全球空气质量指南的 24h 滑动均值

  权重确定方法：基于 11 篇 SCI 元分析（2013-2019, Lancet/NEJM/EHP 等）
  的元回归 + 日常感知系数校准, 详见 code/bhi_weight_regression.py
```

**关键升级**：报告必须**引用** `bhi_weight_regression.py` 输出的
`results/bhi_weight_regression_report.md`，把数据驱动权重 (0.568, 0.093, 0.339)
与论文权重 (0.55, 0.15, 0.30) 的偏差表格放到附录 A 中。

### 🟡 P1：强烈建议（决定是国三还是国二）

#### P1-1：跑通新增的物理约束损失

把 `code/physical_constraint_loss.py` 集成到 `6_advanced_model_v2.py` 训练循环中：

```python
# 在 6_advanced_model_v2.py 训练循环中追加
from physical_constraint_loss import PhysicalConstraintLoss

physical_loss_fn = PhysicalConstraintLoss(
    scaler_y_mean=scaler_y.mean_[0],
    scaler_y_scale=scaler_y.scale_[0],
    lambda_rate=0.1, lambda_wind=0.05, lambda_neg=1.0,
)

# 替换原有损失
L_q = quantile_loss(pred, yb)
L_phy, comps = physical_loss_fn(pred, y_prev, wind_now, wind_prev)
loss = L_q + L_phy
```

**为什么这个一定要做**：评委一看到"物理约束损失"会立刻想起 PINN 
（Physics-Informed Neural Networks）这个 NeurIPS 顶会方向。
这是**让你的工作从"PM2.5 预测的又一个 TCN"升级为"PM2.5 预测的 PINN 探索"**
的关键差异化点。即使物理约束没有显著提升精度，光是引入这个概念就足够加分。

**预期效果**：精度可能下降 1-2%（因为约束限制了拟合），但模型对极端污染场景
（变化率剧烈）的鲁棒性会显著上升。报告中要做一个"有/无物理约束"的对比实验。

**工作量**：1 天
